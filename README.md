# jaspace.el modernization

このディレクトリは、Satomi I. 氏が公開していた Emacs Lisp
`jaspace.el` の来歴を保存し、現在の Emacs で保守できる形へ段階的に
現代化するための作業場所である。

`jaspace.el` は、日本語の全角空白を可視化し、設定により改行やタブも
表示する minor mode である。確認できている upstream の最終版は 1.1
（ソース内の日付は 2005-02-26）で、GPL-2.0-or-later として公開されて
いる。

原典の取得元、Wayback Machine の保存日時、既知の版、ハッシュ、調査中に
見つかった不整合については [PROVENANCE.md](PROVENANCE.md) に記録する。

## 作業方針

1. upstream のファイルを無改変のまま保存し、出所とハッシュを固定する。
2. 文字コード変換などの機械的変更と、プログラム上の変更を別コミットにする。
3. 現行版の挙動をテストで記録してから内部設計を変更する。
4. 互換性のために残す公開変数・コマンドと、廃止できる古い実装手法を区別する。
5. 原著者による版と、このリポジトリでの保守・変更を混同しない。

最終版 1.1 は保守開始時の基準であって、その内部設計をそのまま維持するという
意味ではない。旧版は新しい実装の直接の土台というより、挙動の変遷、後の版で
複雑な処理が導入された理由、過去の不具合を調べるための一次資料として扱う。

## 参考資料をリポジトリに含める基準

原著者が GPL-2.0-or-later で公開した旧版ソースは、小さく、由来の検証や
回帰調査に役立つため、`ref/` 以下に保存する価値がある。ただし通常の Emacs
パッケージを作る際には配布物から除外する。

一方、保存したWebページに付随する Wayback Machine の JavaScript、CSS、
再生用アセットは、コード開発にはほぼ寄与せず、jaspace.el と同じライセンスが
適用されるとも限らない。そのため、公開リポジトリには原則として含めず、
URL、保存日時、必要なハッシュを文書に残す。スクリーンショットは表示仕様を
確認する材料にはなり得るが、必要性が生じるまではURLによる参照で足りる。
